# Samsara Festival App 🎸

Full-stack web application for managing a modern music festival — includes user authentication, ticket sales, lineup scheduling, merch store, and an internal admin dashboard.

## Tech Stack

- **Frontend**: React, Vite, TypeScript, Tailwind CSS, Redux Toolkit, React Router, Zod
- **Backend**: Node.js, Express, TypeScript, PostgreSQL, Prisma or Drizzle
- **Auth**: JWT & Google OAuth 2.0
- **Payments**: Stripe (test mode)
- **Email**: Nodemailer / Resend
- **Tooling**: ESLint, Prettier, Husky, lint-staged, Vitest, Docker
- **Hosting**: Vercel (frontend), Render (backend + DB)
